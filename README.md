# 42cursus

Individual projects from the 42 Seoul curriculum. All written solo.

## Projects

### Systems & C

| Project | Description | Key concept |
|---|---|---|
| [libft](libft/) | Reimplementation of the C standard library | memory, strings, linked lists |
| [ft_printf](ft_printf/) | Reimplementation of `printf` | variadic functions, format parsing |
| [get_next_line](get_next_line/) | Read a file line by line | static variables, fd buffering |
| [pipex](pipex/) | Replicate `cmd1 \| cmd2` shell piping | `fork`, `execve`, `pipe` |
| [push_swap](push_swap/) | Sort two stacks with minimum instructions | binary radix sort, bit manipulation |
| [philosophers](philosophers/) | Dining philosophers problem | threads, mutexes, deadlock prevention |
